# TACITUS's research guide

The pipeline uses TACITUS App's original notebook-carrying pixel guide. The optimized WebP is the same edition used on the company website and GitHub organization profile. It identifies the reusable-context work; it does not imply that a model or human reviewer has checked an output.

The product family keeps three distinct companions: TACITUS's green guide, Wind Tunnel's existing teal Kite and DOXA's plum reader owl. [See the products](https://tacitus.me/).
