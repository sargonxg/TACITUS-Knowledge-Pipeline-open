# Syria negotiation briefing — historical-source exercise

Task: prepare a desk note before a negotiation-policy meeting. Identify who was asked to do what, retain the historical timetable, and list what cannot be inferred from the text. This frozen example uses UN Security Council resolution 2254 (2015), not live events.

The exact normalized transcription and original PDF URL come from the public [Syria research toolkit](https://github.com/sargonxg/Syria-political-analysis/blob/main/data/semantic-documents/unsc-2254.json). Source hashes apply to the normalized text, not the PDF. The selected layer includes paragraphs 2, 4 and 5; the transcription also contains paragraph 8. Coverage limitations remain explicit. No expert approval or current-status finding is claimed.
