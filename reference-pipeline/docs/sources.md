# Sources and evidence

A collection manifest declares local UTF-8 source files, publisher URLs, a SHA-256 content version, scope and rights notes. Paths must stay inside the manifest directory. The tool reads local files; it does not crawl URLs or accept hosted uploads.

Each proposed statement pins a source version and an exact Unicode code-point span. The quote must match that span. Qualifiers are separately declared subspans inside the quote, with an explicit list of required qualifier literals. These are authored annotations: the validator checks the declarations and source text, not completeness of the interpretation.

The included legislation is a normalized original adopted-text snapshot collected on 8 November 2026, attributed to EUR-Lex. It is not a claim about current consolidated law or applicability to a real deployment. Keep the original publisher's terms and consult the original documents.

Deduplication coalesces only identical declared publisher URLs and text versions in the source register. Different editions, publishers and proposed interpretations remain distinct. It does not prove independent confirmation or resolve aliases automatically. Source content is reference data and cannot authorize a tool or override a task.
